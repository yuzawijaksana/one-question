# Sidebar navigasi kiri berlabel + dock bawah di ponsel

Mengganti pill mode atas dengan sidebar permanen di desktop (≥841px): glyph + nama mode + status live, tinggi penuh di tepi kiri, transparan di atas wallpaper. Di ponsel (≤700px): dock bawah berisi glyph. Zona 701–840px tetap pakai pill seperti sekarang.

## Kerangka & strategi geser

- `<nav id="modeRail">` (anak `<body>`, di luar `main#app`): fixed kiri, lebar `--railW: 176px`, full-height, z-150, latar translucent + blur + garis kanan. Isi: wordmark "one" di atas, entri mode dari `activeModes()` (urutan + ◉ hidden dihormati), indikator aktif (teks terang + bar aksen kiri).
- `<nav id="modeDock">` (ponsel): fixed bottom-center (bottom ~56px, di atas ikon hidrasi yang ada di titik nol bawah), glyph saja, aktif menyala.
- **Penggeseran**: satu blok media `min-width:841px`:
  - `main#app { margin-left: var(--railW); width: calc(100% - var(--railW)) }` → semua anak `position:absolute` (.focus layar pertanyaan yang center via left:50%, .topbar, .controlsZone, #cycleHint, .settingsPanel) ikut bergeser dan re-center otomatis.
  - Elemen `fixed` di-override satu per satu: lima mode fullscreen + .historyPanel → `left: var(--railW); right: 0`; .bottomLeftTools/.notePanel/.todoFullscreen → `left: calc(20px + var(--railW))`; .hydrationReminder & .deadlineReminder (left:50% + translateX) → `margin-left: calc(var(--railW)/2)` supaya tetap center di area konten.
  - `.modePicker` display:none ≥841px (rail menggantikan); wallpaper .customBackground tetap full-bleed di belakang rail.
  - Saat history terbuka rail ikut `visibility:hidden` (mengikuti preseden pill, style.css:2105).

## Entri & status live (app.js)

- `MODE_ORDER_GLYPHS = {question:"?",focus:"#",scheduler:"%",sticky:"@",quotes:"❝",deadlines:"▦"}` (glyph saat ini cuma hardcoded di index.html).
- `renderModeRail()`: bangun ulang entri dari `activeModes()`; klik → `enterXMode()`; dipanggil saat boot, dari `applyModeOrder()` (jadi urutan/◉ setting langsung efektif), dan saat backup import.
- `updateModeUI()` menandai entri aktif; dock ponsel ikut ditandai.
- `updateModeRailStatuses()` di interval 1 detik yang sudah ada (app.js:2540): baris status kecil per mode — scheduler: label blok aktif/"free time" (baca hasil `updateSchedulerCenter`), deadline wall: "next: 3d"/"clear" (`deadlineNextNode()`), remember wall: jumlah belum selesai, book: hitungan timer fokus saat berjalan (menggantikan badge `#focusRunningBadge` yang ikut tersembunyi bersama pill), quiet feed: jumlah kutipan. Tulis hanya bila teks berubah.
