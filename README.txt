ONE QUESTION — WALLPAPER ENGINE WEB (FIXED INPUT)

This version uses Wallpaper Engine's native Web user properties for keyboard text input.

IMPORTANT:
1. Open the project in Wallpaper Engine's editor / Installed wallpaper view.
2. Select the wallpaper.
3. Look at the PROPERTIES panel on the right.
4. Use the "Answer" text field there. Do not try to type into the HTML answer line itself.
5. The panel also contains Text parallax, Background parallax, Background scale, and Question cycle sliders.

The HTML textbox remains for normal-browser use, but Wallpaper Engine intentionally does not
allow normal keyboard input to packaged Web wallpaper pages. The native textinput property
is the supported path.

If the Properties panel does not show these controls, make sure project.json is present in
the project folder and re-open/import the project in Wallpaper Engine. Do not rename or delete
project.json.

This is a Web wallpaper. It is not a Scene wallpaper.
